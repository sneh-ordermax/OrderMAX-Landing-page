Discount stacking

See what your offers cost before they stack on the same order.

Discount stacking happens when more than one promotion applies to the same order — a code plus a free gift, or a BOGO plus a free-shipping threshold. It can lift conversion, but without visibility into the combined discount cost it can quietly erode margin. Promotions vs. discounts — and why stacking needs its own view

A discount always reduces price. A promotion is the broader category — it includes discounts, but also gift-with-purchase and BOGO / Buy X Get Y offers, neither of which necessarily lowers the listed price of what a shopper is buying. The reason stacking deserves its own attention is that each promotion type can look fine in isolation — a 10% code, a free gift over $75 — while still combining into an order that's unprofitable once both apply. Tracking discount cost per campaign, and checking the combined total for orders that could trigger more than one, is the difference between a promotion strategy and a margin leak. Offers chosen per cart by AI cart upsell need the same treatment — a recommendation that lands on top of an existing code is exactly the case that stacks unnoticed.

Frequently asked questions

What is discount stacking?

Discount stacking is when more than one promotion applies to the same order — for example, a shopper uses a percentage-off code on a cart that also qualifies for a free gift-with-purchase threshold. Stacking can boost conversion, but without visibility into the combined effect it can also erode margin faster than either promotion would alone.

Is discount stacking risky for margin?

It can be, if the combined discount cost of every active promotion on an order isn't tracked together. A gift-with-purchase offer and a sitewide discount code might each look fine individually while still adding up to an unprofitable order when they stack. The fix isn't avoiding stacking — it's seeing the combined cost before launching.

How do I control which offers can stack on Shopify?

You define which campaigns are allowed to run simultaneously and set the trigger conditions for each — for example, a BOGO offer plus a free-shipping threshold, but not a BOGO offer plus a second product discount. OrderMAX's funnel analytics report the discount cost per campaign, so a combined view is available before you decide what to allow.

What is the difference between a promotion and a discount?

A discount always reduces price. A promotion is the broader term — it includes discounts, but also gift-with-purchase, BOGO/Buy X Get Y, free shipping thresholds, and bundles, none of which necessarily lower the listed price of the item a shopper is buying.

Can I run multiple promotion types at once without a developer?

Yes. OrderMAX's guided campaign setup lets you launch gift-with-purchase, BOGO, and AI-matched upsell campaigns from the same app, with funnel analytics showing the discount cost of each so you can see the combined effect without writing code.
